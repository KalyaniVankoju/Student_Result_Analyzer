# Student Performance Data Analysis

A Python-based data analysis project that uses **Pandas, NumPy, and Matplotlib** to analyze student academic performance, identify performance patterns, study relationships between academic and behavioral factors, and generate visual insights.

The project uses a simulated dataset of 150 students across four branches: CSE, ECE, IT, and MECH.

---

## 📌 Project Overview

Academic performance is influenced by multiple factors such as subject performance, attendance, and study habits.

This project analyzes student performance data to answer questions such as:

- Which subject has the highest and lowest average performance?
- How are students distributed across different performance levels?
- Which students may require additional academic attention?
- Which subject shows the greatest variation in marks?
- How does attendance relate to academic performance?
- How do study hours relate to academic performance?
- How does average performance differ across branches?

The project also generates visualizations and exports the processed dataset with additional analytical columns.

---

## 🛠️ Technologies Used

- **Python**
- **NumPy** — numerical analysis
- **Pandas** — data cleaning, transformation, filtering, grouping, and analysis
- **Matplotlib** — data visualization
- **CSV** — data storage
